三种接入方式,按需要选。Three ways to connect. Pick what you need.

系统代理System proxy

顶栏一个开关。别的程序已经占着系统代理时,Hop 不会抢;只清除指向自己的代理,退出时还原。One switch in the header. If another app already holds the system proxy, Hop leaves it alone; it clears only a proxy that points at itself, and puts things back when it quits.

TUN

接管所有应用的流量。通过一个只装一次的特权辅助组件实现,内核按 TUN 需要的权限运行,Hop 本身不以管理员身份运行。Carries every app's traffic. A small privileged helper, installed once, gives the core the rights a TUN needs, so Hop itself never runs as administrator.

局域网共享LAN sharing

手机和同一网络里的其他电脑,把这台电脑的地址填成 HTTP 或 SOCKS5 代理即可。默认关闭,开启后需要账号密码,只回应私有网络。Phones and other computers on the same network use this computer's address as an HTTP or SOCKS5 proxy. Off by default; once on it asks for an account, and only private networks are answered.

你可能想知道的几件事。A few things you may want to know.

Hop 提供节点或订阅吗?Does Hop provide servers or subscriptions?

不提供。你需要自己的订阅链接,或者自己的节点(粘贴节点链接或 Clash 配置)。请遵守你所在地区的法律法规。No. You bring your own subscription link or your own nodes (paste node links or a Clash config). Follow the laws where you live.

能和其他 Clash 客户端一起装吗?Can it sit beside another Clash client?

可以。Hop 不读写其他客户端的文件或进程,默认端口也避开了它们常用的端口。系统代理同一时间只能指向一个程序:别的程序占着时,Hop 会拒绝抢。Yes. Hop reads and writes nothing of another client, and its default ports stay clear of theirs. The system proxy can point at only one program at a time: if another holds it, Hop declines to take it.

为什么 TUN 要装辅助组件?Why does TUN install a helper?

TUN 需要管理员权限才能接管网络。Hop 自己不以管理员运行,而是让一个很小的辅助组件(macOS 上是 LaunchDaemon,Windows 上是服务)来启动内核。只在你开 TUN 时才需要,装一次、授权一次。A TUN needs administrator rights to take over the network. Hop never runs as administrator; a small helper (a LaunchDaemon on macOS, a service on Windows) starts the core instead. It's needed only when you turn TUN on, installed once with one authorization.

macOS 提示「已损坏」或「无法打开」怎么办?macOS says the app is damaged or can't be opened.

用上面的安装命令装,不要用浏览器下载的文件。浏览器下载的文件会带上隔离标记,而 Hop 目前没有 Apple 开发者证书,macOS 会因此拒绝打开;命令行下载不带这个标记。Install with the command above, not a file downloaded in a browser. A browser download carries a quarantine mark, and Hop has no Apple developer certificate yet, so macOS refuses it; a download from the command line carries no such mark.

Windows 的 SmartScreen 拦住了安装包?Windows SmartScreen blocks the installer.

安装包还没有代码签名。点「更多信息」,再点「仍要运行」。用上面的 PowerShell 命令安装一般不会遇到这个提示。The installer isn't code signed yet. Choose "More info", then "Run anyway". Installing with the PowerShell command above usually avoids the prompt.
